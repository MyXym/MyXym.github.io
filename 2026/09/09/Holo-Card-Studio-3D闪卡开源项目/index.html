Holo Card Studio-3D闪卡开源项目

发布于 2026-09-09

一句话生成 3D 全息闪卡：Holo Card Studio 项目全拆解

对 AI 说一句“给我做一张赛博朋克风的机械猫闪卡，背景霓虹雨夜，编号 No.007”，就能拿到一张能在浏览器里拖拽、翻面、随视角流光溢彩的 3D 全息卡，外加一份可以继续编辑的 Blender 工程——这就是最近在中文 AI 圈快速刷屏的开源项目 Holo Card Studio。

  • 项目地址：https://github.com/EverettFish/holo-card-studio
  • 项目类型：Codex Skill（给 AI 编程助手用的“技能包”）
  • 一句话介绍：把一句自然语言描述（或一张参考图），变成 可交互的 Three.js 网页 + 可编辑的 Blender 工程
  • 数据快照（2026-09-09）：约 1.2k Star / 177 Fork，项目 9 月 7 日创建，两天破千，已被多家 AI 产品站收录
  • 实现教程灵感来源：小红书 @乌托邦的香蕉 🍌（README 里作者专门致谢了这位大佬）

一、它是什么？

Holo Card Studio 是一个 Codex Skill。 简单说，Skill 就是放在 ~/.codex/skills/ 目录里的一套“操作手册 + 脚本”，Codex 遇到相关任务时会自动读取它，按里面的流水线一步步执行。

这个 Skill 把一条很长的制作流水线压缩成了一句话交互：

  1. 你说：“用 holo-card-studio 给我做一张水墨风的锦鲤闪卡，文字用书法体，编号 No.001”（或者直接上传一张参考图：“照这张图做，保留人物和构图，背景换成星空”）
  2. Codex 做：先复述卡片规格和你推断的设计细节 → 用图像生成工具画出四层图 → 生成透明文字层 → 写入卡片配置 → 调用 Blender 搭建场景 → 导出几何并组装成 Three.js 网页 → 启动本地服务并真的在浏览器里测试拖拽、翻面、滑块和手机布局 → 交付

你只负责“想”，剩下的脏活累活它全包了。

二、你会收到什么？

交付物 用途
本地网页链接 在浏览器里拖拽旋转、翻到背面、拉滑块看镭射变化
card.blend 可编辑的 Blender 工程，继续调材质、换灯光、出渲染
assets/ 四层图 主体 / 背景 / 线稿 / 文字分层存放，想换哪层换哪层
card-config.json 改名字、改编号、改稀有度、改属性文字
渲染图 直接发朋友圈 / 群聊

注意：Skill 本体只含代码和文本，很轻；你生成的画作、.blend、模型都待在你自己的输出项目里，不会污染技能目录。

三、能拿它做什么？

🐱 给自家毛孩子发一张“传说级”卡

上传猫主子的照片，加一句“传说稀有度、金色边框、名字叫布丁”。主体保留它本猫的神态和构图，背景、线稿全新绘制。拖一拖：猫往前凸、背景往后退、镭射彩虹随角度流动。

🎮 给独立游戏做角色卡牌

一个角色一句描述，批量出一整套战士、法师、盗贼、Boss。每张卡自带 card-config.json，稀有度、编号、属性都在里面，改完重跑一遍流水线即可更新。

🏢 团队周年纪念 / 新人入职卡

头像当主体、部门色当背景、Slogan 当文字层，每人一张，网页链接一发，大家能翻一下午。

🎁 情人节 / 生日 / 纪念日

“复古胶片风、粉金配色、背面写一句话”。对方在手机上转着看，翻到背面看到那句话——仪式感拉满。

🎤 演讲 / 发布会的“彩蛋物料”

产品发布做一张产品卡，PPT 最后一页丢个链接：“扫码看会闪的那种”。响应式网页，手机横竖屏都能玩。

🖌️ 设计师的材质实验场

card.blend 是真正可编辑的工程，共享节点组里是中文命名的“缩放 / 深度 / 视差效果”，镭射条纹、星光、线稿发光都是独立可调的材质节点。想研究全息卡是怎么“闪”起来的，打开它就是最好的教材。

四、原理：一张闪卡是怎么“叠”出来的

四层图 + 视差 = 立体感

整张卡由四层图叠在同一块画布上，再用视差把它们在空间里“撑开”：

视线一变，各层相对位移不同，卡片就有了真实的“厚度”。

Blender 材质：全息感的核心

  • 镭射彩虹：粉色-黄色-蓝色-白色渐变条纹，相位跟着视角走——转到哪闪到哪，而不是简单的随时间播放动画
  • Voronoi 星光：尺度 + 动画噪声，从零星几颗到满天星
  • 金色卡边：卡片正反两面 + 侧边使用独立材质槽
  • 线稿发光：强度与遮罩密度可调，从“淡淡勾边”到“霓虹描边”

Three.js 网页：和 Blender 里看到的一致

浏览器端用 Three.js 按同一套 UV 公式重建这四层合成，所以 Blender 里看到什么，网页里就是什么。工程上有一个很关键的约定：导出真实 Blender 几何（材质名以 web_front / web_edge / web_back / web_gold 作为浏览器端契约），而不是“把截图贴在一个平面上假装是模型”。

另外作者在代码注释里留下了一个很硬的细节：仅靠 UV 居中 + 法线变换做不出完整的视角相关视差，还必须把观察方向变换进卡片平面、除以一个有界的法线分量、再按带符号的深度去偏移 UV。因为自定义着色器图无法通过 glTF 直接迁移，所以网页端是“导出几何 + 前端重建材质”。

五、怎么上手？

1. 环境要求

  • Python 3 + Pillow
  • Node.js + npm
  • Blender 不用自己装：流水线会自动把官方便携版下载到 <项目>/tools/，校验 SHA-256，项目自带、互不干扰

2. 安装

把这个目录放进 Codex 的 skills 目录即可：

3. 开口

在 Codex 里直接说人话，例如：

“用 holo-card-studio 给我做一张水墨风的锦鲤闪卡，文字用书法体，编号 No.001”

Codex 会先把卡片规格和它推断的细节说给你听，确认后开工：画图 → 生成文字层 → 写配置 → 跑流水线 → 起本地服务 → 真正打开页面测拖拽、翻面、滑块和手机布局 → 交付。

六、可以调哪些“旋钮”？

流水线出厂就是一套顺手的参数，也都留了口子（以 card-config.json 为主）：

  • 视差强度：主体默认 scale 1.25 / depth 0.4，背景 depth -0.25，想更“跳”就往上加
  • 镭射条纹：密度、扭曲度、角度，以及粉-黄-蓝-白渐变
  • 线稿发光：强度与遮罩密度
  • 星光：Voronoi 尺度 + 动画噪声
  • Blender 界面语言：默认简体中文，存在项目本地配置里，一句话可换

七、目录速览与工程亮点

几个值得点赞的工程细节：

  • 自带依赖管理：Blender 便携版自动下载 + SHA-256 校验 + 项目本地隔离，互不干扰
  • 校验前置：validate_assets.py 检查四层图的尺寸、透明度和对齐；verification.md 是交付前的验收清单，避免“没验证就说做好了”
  • 干净可分享：package_skill.py 按白名单只打包文本文件，输出 ZIP 拿走即用
  • 许可证：MIT，但明确声明生成的画作与用户上传的参考图不随仓库分发、也不在软件许可范围内——这是很清醒的边界意识

八、适合谁？有哪些注意事项？

适合人群

  • 想给家人、朋友、对象做一张独一无二卡片的“非程序员”
  • 独立游戏作者（批量角色卡 + 抽卡预告物料）
  • 设计师 / 想研究“全息卡材质到底怎么闪”的技术美术
  • 想体验“AI 绘画 → Blender 建模 → Web 交互”完整流水线的学习者

注意事项

  • 依赖 Codex 的图像生成能力（上传参考图时尤其如此），Skill 明确要求优先用内置图像工具，而不是偷偷换成需要 API Key 的付费服务
  • 自动生成的线稿偶尔会“漂移”，需要和原图对比校验，必要时重生成
  • 浏览器网页与 Blender 渲染不是像素级完全一致（材质图是前端重建的），追求极致出图建议用 card.blend 出渲染
  • 需要本机有 Python 3 / Node.js 环境，Blender 会自动下载

结语

这个项目最迷人的地方，是它把“一句话 → 一个有实感的 3D 作品”的链路做到了几乎零门槛：既有 AI 生成艺术的随性，又有 Blender/Three.js 的硬核工程，还保留了“所有图层和工程都可编辑”的开放性。无论你是想给毛孩子做张传说卡，还是想研究镭射材质，都值得 clone 下来玩一玩。

“想好第一张卡画谁了吗？✨”
